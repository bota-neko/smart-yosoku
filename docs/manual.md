# smart-yosoku 使い方ガイド（説明書）

毎日の納品を記録して、明日つくる数をらくに決めるためのサービスです。
このガイドは、はじめての方でも今日から使えるように書いています。

> このサービスは、**「どのお店に・何を・いくつ卸したか」** を毎日記録すると、
> **「明日いくつ作ればいいか」** を自動で計算してくれます。むずかしい設定は後回しでOK。

## メニューは4つだけ
パソコンは画面の左、スマホは画面の下にあります。

| メニュー | 何をする画面か |
|---|---|
| **あした作る数**（ホーム） | 明日いくつ作ればいいかを見る。「1週間」に切り替えると、1週間分の見込みも見られます。 |
| **きょうの納品** | 今日どのお店に何個卸したかを記録する（納品書を撮るだけでもOK）。 |
| **ふりかえり** | この30日の「捨てた金額」「売り切れ」「見込みの当たり具合」を見る。 |
| **設定** | 商品・お店・地域・APIキーの登録。 |

## 毎日の使い方
この2つを回すだけ。数分で終わります。

### 1. 今日の納品を記録する（メニュー「きょうの納品」）
いちばん簡単なのは **「納品書を撮る」** です。
- スマホは「納品書を撮る」、パソコンは「撮った写真を選ぶ」
- お店・日付・商品ごとの数を自動で読み取ります
- 確認画面で数字や商品を直して「入力欄に反映する」→ 最後に **「保存する」**
- ケース表記は商品の「ケース入数」で個数に直します。読み間違いもありうるので、保存前に必ず見直してください。写真は保存されません。

手で入れるときは、お店の一覧から**お店を押して**、商品ごとに卸した数を入れて「保存する」。
- 「前の日と同じ」「先週と同じ」を押して、数字を直すだけでもOK
- 一覧で、お店ごとに「記録済み／まだ」がわかります

空欄は「まだ入れていない（未入力）」、**0**は「今日はゼロだった」という意味で区別されます。

**ふだんは閉じている項目（必要なときだけ）**
- **廃棄・売り切れ**：入力欄の下の「廃棄・売り切れも記録する」から。記録すると「ふりかえり」で金額が見られます。
- **特売・イベント・店休日など**：画面いちばん下から。今日の分と明日の予定に印をつけると、作る数の見込みに反映されます。
- **天気・気温・祝日**：毎日自動で取ってくるので、入力はいりません。

### 2. 明日いくつ作るかを見る（メニュー「あした作る数」）
商品ごとに、明日作る数が大きく出ます。商品を押すと**お店ごとの内訳**、さらにお店を押すと**見込みの根拠**が見られます。
材料の仕入れや仕込みの計画には「1週間」に切り替えて、期間合計を目安にしてください。

## 最初の設定（一度だけ）
メニュー「設定」から登録します。むずかしい設定は、必要になってからで大丈夫です。

- **商品**：「商品名」と「単位（丁・パック・kgなど）」を入れて追加。↑↓で並び替え（入力画面の順番になります）。
- **お店**：お店の名前を入れて追加。
- **地域**：天気を取る地域（市区町村名）。
- **APIキー**（納品書を撮って記録したい人だけ）：ご自身の Claude APIキーを登録します。利用料はご自身の Anthropic アカウントに請求されます（1枚あたり1円前後）。取り方は設定画面に書いてあります。PCで登録すればスマホでもそのまま使えます。

> **お試し**：「設定」→「商品」の「サンプルに戻す」で見本データを入れると、登録をとばして動きを試せます。

### くわしい設定（使い込む人だけ）
次の3つは**設定しなくても動きます**。慣れてきたら「設定」→「お店」で各お店を開いて調整してください。
- **取扱商品**：そのお店に卸す商品だけに絞る（例：食堂には厚揚げだけ）
- **ケース単位で卸す**：数をケースの倍数へ切り上げる（例：厚揚げ 1ケース20パック）
- **ゆとり**：見込みより何%多めに作るか（初期は10%）

## 言葉のやさしい早見表
| 画面の言葉 | 意味 |
|---|---|
| お店（卸先） | 商品を納める先のお店。 |
| 作る数 | 全部のお店へ卸す数の合計。明日用意するとよい数。 |
| 見込み | 売れそうな数（お店で必要になりそうな数）。 |
| ゆとり | 足りないと困るので**多めに作る割合**。 |
| 当たり具合 | 見込みがどれくらい当たったか（よく当たる／まずまず／ずれが大きめ）。 |
| ケース入数 | **1ケース＝何個**か。 |

## 作る数はどう決まる？
むずかしい計算は自動です。考え方だけ知っておくと安心です。

```
売れそうな数 ＋ ゆとり分 ＝ お店へ卸す数   →   全部のお店の合計 ＝ 作る数
```

- 「売れそうな数」は、これまでの納品実績（曜日ぐせ・季節・直近の伸び）と、天気・特売・祝日から計算します。
- データがたまるほど当たりやすくなります。
- 新しいお店・商品は、実績がまだ無いので最初は「参考値」と出ます。使ううちに確かになります。

## よくある質問

**Q. 入力した数字は、どこへいくの？**
そのまま「過去の納品実績」として保存され、次の日からの見込みに使われます。

**Q. 「0」と「空欄」はどう違うの？**
空欄＝まだ入力していない（未入力）。0＝その日は卸しがゼロだった、という記録です。ゼロの日はきちんと 0 と入れてください。

**Q. 納品書を撮っても、ある商品が取り込まれない**
読み取りは、登録済みの商品・お店と照らし合わせて取り込みます。登録していない商品は「取り込まない」になるので、先に「設定」→「商品」で登録してください。そのお店の取扱商品に入っていない商品も取り込まれません。

**Q. 「当たり具合」はどうやって出しているの？**
過去の各日について「その日より前の記録だけ」で見込みを出し、実際の納品数と比べています。記録が2週間以上たまると表示されます。

**Q. データはどこに保存されるの？**
ログインすると、アカウントごとに分けられたデータベースに保存され、他の人からは見えません。ログインしない「お試しモード」では、このパソコン（ブラウザ）の中だけに保存されます。

## 困ったとき
- **画面の見た目が崩れる** → ページを再読み込み（Mac は ⌘+Shift+R、Windows は Ctrl+Shift+R）。
- **数字が思ったより少ない／多い** → 「あした作る数」で商品→お店を押すと、見込みの根拠が見られます。極端な日があると見込みが引っぱられます。
- **見込みが「参考値」のまま** → データがまだ少ない合図。記録を続けると確かになります。
- **まちがえて入力した** → 「きょうの納品」で日付とお店を選び直して数字を直し、「保存する」で上書きできます。
